# Weed-control products on Amazon.co.jp — a multi-layer category trap

A user asking, in casual language, for "撒在地里防止野草长出来的东西" (something you sprinkle on the ground to stop weeds growing) can mean **at least three physically distinct product classes**. Searching one keyword surfaces all three mixed together, and the highest-rated cluster is often NOT what they want. Classify before ranking — this is the `Highest-Rated ≠ What The User Asked For` principle applied to gardening.

## The three top-level classes (all match a naive 防草 search)

| Class | Japanese keywords | What it physically is | Sprinkled onto soil/sand? |
|---|---|---|---|
| **A. Hardening sand/soil** | 固まる砂 / 固まる土 / 防草砂 / 真砂土 / マサファルト / ガンコマサ / ハイドサイド | A granular material you spread then water → it sets like soft concrete, physically blocking weeds | Yes, but it **cements over** the ground |
| **B. Weed-barrier sheet/gravel** | 防草シート / 瓦チップ / 砂利 / 防犯砂利 | A woven fabric you lay down, or decorative gravel spread on top | No — it's a **layer**, not a sprinkle-in product |
| **C. Granular herbicide (the "药"/medicine)** | 除草剤 粒剤 / 顆粒 / まくだけ | Chemical granules you sprinkle into/onto soil; the active ingredient suppresses weeds | **Yes** — this is the one that means "撒药到土里" |

**Disambiguation cue (from a real request):** the user said "我是要药撒到地里边…不是防草层那种" (I want the *medicine* sprinkled into the ground, not the barrier-layer kind). The word 药/medicine + "into the soil" + "not a layer" → **Class C, 除草剤 粒剤**. If a user says "硬化/固まる/像水泥" → Class A. If "铺/シート/砂利" → Class B.

## Within Class C (granular herbicide) — sub-classify again before recommending

| Sub-type | Keywords | Key property | When to recommend |
|---|---|---|---|
| **土壌処理型 (residual/pre-emergent)** | 長期間持続 / 6カ月 / 効果1年 / ネコソギ / クサノンEX / カソロン | Active stays in soil 6 mo–1 yr, stops weeds *germinating*. **Will also kill/suppress wanted plants nearby** — only for places you want nothing to grow (空地, 駐車場, 犬走り, 围墙边) | User wants long-term bare ground |
| **茎葉処理型 (foliar/contact)** | speed / 速効 / シャワー / 液体 (often液体, not粒) | Kills existing leaves, little soil residual | User wants to kill what's already there but keep planting later |
| **芝生用 (lawn-selective)** | シバキープ / シバニード / 芝生用 | Selective — kills weeds but spares turf grass | ONLY on a lawn; useless elsewhere |
| **水稲/畑作用 (rice/crop field)** | 水稲用 / 畑作 / 1キロ粒剤 / バサグラン / ゲパード | Agricultural, crop-specific | Almost never what a home/garden user wants — drop as noise |

**Critical buy-side warning to always surface:** 土壌処理型 granules leave active chemical in the soil for months. They must NOT be sprinkled where the user still wants flowers/vegetables/trees to grow — it suppresses those too. Ask whether there are plants to preserve nearby; that single question decides 土壌処理型 vs 茎葉処理型.

**Form factor mixed into 粒剤 searches:** a 除草剤 粒剤 keyword also surfaces 液体/シャワー (spray/liquid) products with high ratings (ラウンドアップ, アースカマイラズ, ネコソギシャワー commonly 4.3★ / thousands of reviews). These are NOT 粒 (granules) — flag them separately when the user explicitly asked for the sprinkle-granule form.
